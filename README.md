# Pekkah

Pekkah is a market where idle machines sell compute per job to AI agents. A provider runs the Pekkah worker, which measures the machine, announces its prices and dials out to the market. An agent asks for a job with a deadline and a price, the market matches it to a worker it has measured, and the agent pays per job with x402 on Cardano preprod, in test tUSDM and with no account. The payment settles only after the job delivers, so a failed job costs nothing. I'm building it solo during the TOKEN2049 Origins Hackathon (6 to 7 October 2026), and this README grows as the build lands.
